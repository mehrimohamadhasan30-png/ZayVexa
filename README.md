# 🟠 ZayVexa Network

**شبکهٔ Minecraft Java 1.20.1 با تم نارنجی و مشکی**  
وضعیت پروژه: **در حال برنامه‌ریزی و ساخت — هنوز آمادهٔ انتشار عمومی نیست.**

ZayVexa با هدف ساخت یک شبکهٔ کوچک و پایدار شامل Lobby و Survival مبتنی بر Slimefun ساخته می‌شود. این مخزن محل نگهداری فایل‌های پروژه، مستندات و تصمیم‌های فنی است.

> **وضعیت مهم:** Datapack لابی یک سازندهٔ اولیه است، نه فایل دنیای کامل؛ هنوز در Minecraft Java 1.20.1 آزمایش نشده است. فهرست پلاگین‌ها نیز پیشنهادهای در حال بررسی است و به معنی نصب یا تأیید سازگاری نیست.

## آزمایش Datapack لابی

1. در **Minecraft Java 1.20.1** یک دنیای Creative تازه بساز.
2. بازی را ببند و پوشهٔ `ZayVexaLobby` را از [اینجا](lobby/datapacks/ZayVexaLobby/) در پوشهٔ `datapacks` همان دنیا قرار بده.
3. دوباره وارد دنیا شو و `/reload` را اجرا کن.
4. سپس `/function zayvexa:build` را اجرا کن.
5. برای رفتن به نقطهٔ پیشنهادی شروع: `/tp @s 0 81 0`

**احتیاط:** این تابع بلوک‌ها را در مختصات ثابت می‌سازد؛ فقط در دنیای آزمایشی تازه اجرا کن. قبل از استفاده از نسخهٔ واقعی، فایل‌ها باید در نسخهٔ هدف آزمایش شوند.

## معماری هدف

```text
Velocity Proxy
├── Lobby (Paper)
└── Survival (Paper + Slimefun)
```

این فقط معماری پیشنهادی است. تنظیمات پروکسی، اقتصاد مشترک، مجوزها، پایگاه داده و نسخه‌های دقیق پلاگین‌ها هنوز باید انتخاب و آزمایش شوند.

## اصول پروژه

- سازگاری واقعی با Minecraft Java 1.20.1؛ نه صرفاً ادعای سازگاری.
- نگهداری جداگانهٔ فایل‌های اجرایی، برنامه‌ریزی و مستندات.
- پشتیبان‌گیری از دنیاها و داده‌های پلاگین‌ها پیش از تغییرات مهم.
- عدم بارگذاری رمزها، کلیدها، فایل‌های محلی جهان و لاگ‌های حجیم در مخزن.
- تغییرات بزرگ در شاخهٔ جداگانه و از طریق Pull Request.
- اعلام صریح موارد آزمایش‌نشده.
