# ZayVexa Network

## لابی سایبرپانک — Minecraft Java 1.20.1

فایل‌های دیتاپک بدون پلاگین در پوشهٔ [lobby](lobby/) قرار دارند.

### نصب و آزمایش
1. یک دنیای تازهٔ Creative در Minecraft Java 1.20.1 بساز و از بازی خارج شو.
2. از بخش [ZayVexaLobby datapack](lobby/datapacks/ZayVexaLobby/) پوشهٔ `ZayVexaLobby` را دانلود کن یا مخزن را به‌صورت ZIP بگیر.
3. پوشهٔ دیتاپک را در `.minecraft/saves/<نام‌دنیا>/datapacks/` کپی کن.
4. دوباره وارد دنیا شو و اجرا کن:
   `/reload`
5. سپس اجرا کن:
   `/function zayvexa:build`

راهنمای کامل فارسی: [README_FA.txt](lobby/README_FA.txt)

**نکته:** این دیتاپک سازندهٔ لابی است، نه یک سیو کامل دنیا با فایل `level.dat`. هیچ پلاگینی لازم ندارد.
