# وضعیت فعلی ZayVexa

آخرین جمع‌بندی: ۲۰۲۶-۱۰-۲۹

## هدف کلی

ساخت یک شبکهٔ کوچک Minecraft Java با نسخهٔ هدف **1.20.1**، تم نارنجی و مشکی و تمرکز اولیه روی Lobby و Survival مبتنی بر Slimefun. اندازهٔ هدف اولیه حدود **۵ تا ۱۰ بازیکن هم‌زمان** است. پروژه هنوز آمادهٔ انتشار عمومی یا اجرای پایدار تأییدشده نیست.

## وضعیت اجزا

| بخش | وضعیت فعلی | نکته |
|---|---|---|
| مخزن GitHub | موجود | مخزن مرجع پروژه: [ZayVexa](https://github.com/mehrimohamadhasan30-png/ZayVexa) |
| مستندات معماری | پیش‌نویس ثبت‌شده | هنوز پیاده‌سازی و آزمایش شبکه نیست |
| ماتریس پلاگین‌ها | گزینه‌های پیشنهادی | نصب یا سازگاری نهایی تأیید نشده |
| Datapack لابی | فایل‌های سازنده موجود | دنیای کامل ذخیره‌شده نیست و در بازی آزمایش نشده |
| اتصال Velocity | برنامه‌ریزی‌شده | راه‌اندازی و تنظیم امنیتی انجام‌شده محسوب نمی‌شود |
| Paper Lobby/Survival | گزینهٔ معماری | نسخهٔ دقیق و پیکربندی هنوز نیازمند بررسی است |
| Slimefun | هسته و افزونه‌های منتخب در حال برنامه‌ریزی | نسخه‌ها و تعامل آیتم‌ها باید آزمایش شوند |
| اقتصاد و بازار | مدل ترکیبی انتخاب شده | راهکار نهایی و جلوگیری از سوءاستفاده هنوز باید آزموده شود |
| انتشار عمومی | انجام نشده | به گذراندن معیارهای پذیرش نیاز دارد |

## معماری هدف پیشنهادی

```text
بازیکن
  |
Velocity Proxy
  |---- Lobby (Paper)
  |---- Survival + Slimefun (Paper)
          |---- اقتصاد مشترک، فقط با راهکار سازگار و آزمایش‌شده
```

این طرح معماری است، نه اعلام وجود سرورهای متصل و فعال.

## تصمیم‌های گیم‌پلی ثبت‌شده

- نسخهٔ هدف Minecraft Java: **1.20.1**.
- Slimefun سفارشی برای تجربهٔ ZayVexa در نظر گرفته شده است.
- طبق انتخاب ثبت‌شدهٔ کاربر، همهٔ آیتم‌های Slimefun از ابتدای بازی برای همهٔ بازیکنان در دسترس باشند؛ پیشرفت و اقتصاد باید طوری طراحی شود که این دسترسی باعث بی‌ارزش‌شدن بازی نشود.
- اقتصاد ترکیبی: فروشگاه مرکزی با قیمت‌های ثابت و بازار بازیکنان.
- انتخاب فعلی برای فروشگاه و بازار: بررسی پلاگین‌های آماده؛ برای Slimefun استفاده از هستهٔ موجود همراه تنظیمات و افزونه‌های منتخب، نه ساخت هسته از صفر.
- محافظت زمین: GriefPrevention در طرح فعلی.
- PlaceholderAPI برای متغیرهای معتبر و نمایش اطلاعات؛ هر متغیر باید با افزونه و نسخهٔ واقعی تأیید شود.
- ظاهر شبکه و اسکوربورد: نارنجی و مشکی، سبک Network.
- بودجهٔ فعلی: فعلاً بودجه‌ای برای هزینه‌های پروژه در نظر گرفته نشده؛ پیش از انتخاب سرویس پولی باید هزینه روشن شود.

## محدودیت‌های محیط هدف که پیش‌تر گزارش شده‌اند

اطلاعات زیر از گفت‌وگوهای قبلی آمده‌اند و باید قبل از نصب دوباره بررسی شوند:

- سیستم میزبان گزارش‌شده: Windows 10، بیلد 19045.6691.
- پردازندهٔ گزارش‌شده: Intel Core i3 M 350، فرکانس 2.27GHz.
- حافظهٔ گزارش‌شده: 8GB RAM (حدود 7.8GB قابل استفاده).
- فضای دیسک در گزارش‌های قبلی محدود بوده؛ یک بار حدود 14GB فضای خالی در درایوی 100GB و 17GB در درایو E: گزارش شده است. این اعداد فعلی و قطعی نیستند.
- Java نصب‌شدهٔ گزارش‌شده قبلی: Java 8 نسخهٔ 32 بیتی؛ برای Paper 1.20.1 باید نسخهٔ Java موردنیاز انتخاب و جداگانه بررسی شود.
- کاربر گزارش کرده رایانهٔ شخصی‌اش Minecraft را حداکثر تا 1.16.5 اجرا می‌کند و گوشی Android را نیز با یک لانچر اجرای Java Minecraft استفاده می‌کند. این مورد روی روش آزمایش و تحویل فایل‌ها اثر دارد، اما نام و قابلیت دقیق لانچر مستقل از گزارش کاربر تأیید نشده است.
