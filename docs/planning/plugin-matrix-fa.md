# ماتریس بررسی پلاگین‌های ZayVexa

**وضعیت کلی:** برنامه‌ریزی و مقایسه؛ هنوز نصب یا آزمایش نهایی نشده است.  
**هدف:** Minecraft Java 1.20.1، شبکهٔ کوچک با Velocity و Paper.

| بخش | گزینهٔ مورد بررسی | نقش | وضعیت / ریسک |
|---|---|---|---|
| پروکسی | Velocity | اتصال Lobby و Survival | نیازمند بررسی نسخه، تنظیمات forwarding و امنیت |
| هستهٔ سرورها | Paper | اجرای سرورهای Lobby و Survival | نسخهٔ دقیق باید برای 1.20.1 انتخاب شود |
| مجوزها | LuckPerms | گروه‌ها و دسترسی‌ها | نیازمند تعیین روش همگام‌سازی شبکه |
| اقتصاد پایه | Vault + ارائه‌دهندهٔ اقتصاد | رابط سازگاری اقتصاد | Vault به‌تنهایی اقتصاد ایجاد نمی‌کند |
| ابزارهای عمومی | EssentialsX | ابزارهای پایه و برخی فرمان‌ها | هر ماژول و مجوز باید جداگانه بررسی شود |
| محتوای اصلی | Slimefun | پیشرفت فنی و آیتم‌ها | هسته و افزونه‌های دقیق باید برای 1.20.1 بررسی شوند |
| محافظت زمین | GriefPrevention | ادعا و محافظت منطقه | نسخه و متغیرهای PlaceholderAPI نیازمند آزمون |
| ثبت تغییرات | CoreProtect | بررسی و بازگردانی تغییرات | هزینهٔ ذخیره‌سازی و نسخه باید بررسی شود |
| جایگاه و متغیرها | PlaceholderAPI + TAB | نمایش اطلاعات بازیکن و سرور | هر Placeholder باید با افزونهٔ واقعی تأیید شود |
| فروشگاه مرکزی | EconomyShopGUI یا گزینهٔ جایگزین | خریدوفروش با قیمت ثابت | سازگاری و تعامل با آیتم‌های Slimefun باید آزمایش شود |
| بازار بازیکنان | AuctionHouse یا گزینهٔ جایگزین | فهرست‌کردن کالا توسط بازیکنان | جلوگیری از تکثیر آیتم و پشتیبانی از آیتم‌های سفارشی حیاتی است |
| اقتصاد مشترک | XConomy یا گزینهٔ جایگزین | تراز مشترک بین سرورها | پشتیبانی نسخه، پایگاه داده و بازیابی باید مستند و آزمایش شود |

## معیارهای پذیرش هر پلاگین
- نسخهٔ مشخصی برای Minecraft 1.20.1 داشته باشد.
- نیازمندی Java و وابستگی‌ها روشن باشد.
- منبع دانلود رسمی و سابقهٔ نگهداری قابل بررسی باشد.
- تداخل با Slimefun و آیتم‌های سفارشی بررسی شود.
- در صورت استفادهٔ چندسروری، همگام‌سازی داده‌ها مستند باشد.
- ابتدا در محیط آزمایشی و با نسخهٔ پشتیبان بررسی شود.

## تصمیم‌های هنوز باز
- فروشگاه مرکزی و بازار بازیکنان نهایی نشده‌اند.
- نوع و محل پایگاه دادهٔ مشترک نهایی نشده است.
- همگام‌سازی پیشرفت Slimefun بین چند سرور تأیید نشده است.
- نسخه‌های دقیق پلاگین‌ها و افزونه‌های Slimefun انتخاب نشده‌اند.

**قاعده:** این جدول فهرست گزینه‌هاست، نه تأیید سازگاری یا اعلام نصب‌شدن آن‌ها.
