# نمای کلی معماری ZayVexa Network

**وضعیت:** طرح اولیه؛ هنوز روی سیستم یا سرور اجرا و اعتبارسنجی نشده است.  
**هدف نسخهٔ بازی:** Minecraft Java 1.20.1  
**تم بصری:** نارنجی و مشکی  
**مقیاس اولیه:** حدود ۵ تا ۱۰ بازیکن هم‌زمان

## اجزای پیشنهادی

```text
بازیکن
  |
  v
Velocity Proxy
  |
  +---- Lobby (Paper)
  |
  +---- Survival / Slimefun (Paper)
             |
             +---- داده‌های اقتصاد مشترک، فقط با پشتیبانی تأییدشدهٔ پلاگین
             +---- داده‌های اختصاصی Slimefun و جهان
```

این دیاگرام معماری هدف را نشان می‌دهد، نه یک شبکهٔ آماده یا متصل.

## اصول طراحی
1. **سازگاری نسخه:** تمام سرورها، پلاگین‌ها، افزونه‌ها و نسخهٔ Java باید با Minecraft 1.20.1 سازگار باشند.
2. **مرزبندی:** Lobby و Survival سرورهای جدا باشند؛ هرکدام تنظیمات و داده‌های خود را داشته باشند.
3. **اقتصاد مشترک:** فقط از راهکاری استفاده شود که پشتیبانی چندسروری آن مستند و آزمایش شده باشد.
4. **پایداری:** تعداد موجودیت‌ها، ذرات، رداستون و بار افزونه‌ها محدود بماند.
5. **امنیت:** پروکسی و سرورهای پشت آن باید مطابق راهنمای رسمی Velocity ایمن شوند؛ پورت‌های سرورهای داخلی بی‌دلیل در اینترنت باز نباشند.
6. **پشتیبان‌گیری:** از جهان‌ها، تنظیمات و داده‌های هر افزونه به‌صورت جداگانه نسخهٔ پشتیبان تهیه شود.

## محدودیت‌های فعلی
- سخت‌افزار هدف قدیمی و حافظه محدود دارد؛ عملکرد واقعی باید با آزمایش سنجیده شود.
- فضای آزاد دیسک محدود گزارش شده است؛ پیش از دریافت فایل‌های بزرگ یا ساخت سرور باید فضای موجود بررسی شود.
- جاوای نصب‌شدهٔ قبلی Java 8 بوده؛ برای اجرای Paper 1.20.1 باید نسخهٔ سازگار Java، معمولاً Java 17، فراهم و تأیید شود.
- هیچ پلاگین یا نسخه‌ای صرفاً بر اساس نام، سازگار فرض نمی‌شود.
