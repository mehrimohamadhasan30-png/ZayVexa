لابی سایبرپانک ZayVexa — Minecraft Java 1.20.1
================================================

این بسته یک «دنیای ذخیره‌شدهٔ کامل» نیست؛ یک Datapack بدون پلاگین است که با دستورهای خود بازی، بخش‌های اصلی لابی را می‌سازد.

محدودهٔ ساخت:
- کف و محدودهٔ شهر: X/Z حدود -128 تا 127
- ارتفاع کف: Y=79
- محل شروع پیشنهادی: X=0, Y=81, Z=0
- میدان مرکزی و برج Z
- دروازهٔ Survival
- ساختمان اقتصاد
- مرکز راهنمای Slimefun
- تالار افتخارات
- مسیر پارکور و غرفهٔ جایزهٔ روزانه
- دیوار/محدودهٔ عکس گروهی

روش استفاده:
1. در Minecraft Java 1.20.1 یک دنیای Creative جدید بساز.
2. از منوی بازی خارج شو.
3. پوشهٔ datapacks داخل پوشهٔ دنیای ساخته‌شده را باز کن.
4. پوشهٔ ZayVexaLobby را داخل datapacks کپی کن.
5. وارد دنیا شو و دستور /reload را اجرا کن.
6. دستور /function zayvexa:build را اجرا کن.
7. در مختصات 0 81 0 ظاهر شو (دستور /tp @s 0 81 0).

نکات:
- قبل از اجرای تابع، دنیای خالی و جدید انتخاب کن؛ دستورها کف و ساختمان‌ها را در مختصات ثابت می‌سازند.
- این بسته هیچ پلاگین یا مود نیاز ندارد.
- بسته خودش فایل level.dat یا دنیای ذخیره‌شده تولید نمی‌کند؛ Minecraft هنگام ساخت دنیای جدید آن را ایجاد می‌کند.
- بخش‌ها معماری اولیه‌اند؛ نوشته‌های تابلوها، NPCها، اتصال واقعی به سرورهای Velocity و اقتصاد/جایزه به تنظیمات جداگانه نیاز دارند.
- برای تبدیل به دنیای آمادهٔ قابل باز کردن، باید ابتدا در Minecraft اجرا شود؛ بازی یا سروری از سمت سازنده اجرا نشده است.
